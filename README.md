# test-codex

A systematic collection of TypeScript utilities.

## Getting Started

```bash
npm install
```

## Development

```bash
# Run tests
npm test

# Run tests in watch mode
npm run test:watch

# Lint
npm run lint

# Format
npm run format

# Type check
npm run typecheck

# Build
npm run build

# Run all CI checks locally
npm run ci
```

## Project Structure

```
src/          → Library source code
tests/        → Test files
dist/         → Build output (git-ignored)
```
